# 阶段 1：真实对话（P0）

> 主设计见 `docs/agent/0.overview.md`。本文件是 P0 的详细实施清单。

## 目标

把 `useAgentChat` 的 mock 打字机替换为真实多 Provider 流式对话：发送 → main 进程调用 AI SDK → 流式增量事件推回 renderer → 可停止。

## 范围

- 不做：持久化、工具、多会话、上下文压缩、thinking 折叠渲染（后续阶段）。
- 消息只存内存（本轮）。

## 前置

- 无（纯新增，复用 `settings` 的多 Provider 配置）。

## 任务清单

### 1. 契约先行：shared

- [ ] 新建 `src/shared/agent.ts`：`AgentMessageRole` / `AgentToolCall` / `AgentMessage` / `AgentSession` / `AgentEvent`（见主文档 §5.1；Event 含 turn_start / text_delta / thinking_delta / tool_call_* / message_complete / turn_end / error）。
- [ ] 新建 `src/shared/ipc/agentChannels.ts`：`AGENT_CHANNELS`（sendMessage / stop / getRuntimeState）+ `AGENT_EVENT`（见主文档 §5.2）。

### 2. main：provider 层

- [ ] `src/main/agent/provider/createProvider.ts`：读 `settingsService.getModelProviderSettings()`，按 `providers[].type` 映射 `createAnthropic` / `createOpenAI` / `createGoogleGenerativeAI` / `createOpenAICompatible`；从 `defaultModel` 取 (provider, model)。
- [ ] `src/main/agent/provider/stream.ts`：用 `ai` v6 `streamText` 封装，产出 `text_delta` / `thinking_delta` 事件；支持 `AbortController` 中止。

### 3. main：runtime + 事件

- [ ] `src/main/agent/runtime/runAgentLoop.ts`：本轮仅"流式回复"（无工具分支）；维护 messages 与 AbortController。
- [ ] `src/main/agent/events.ts`：事件源，`webContents.send(AGENT_EVENT, evt)`。

### 4. main：service + ipc

- [ ] `src/main/services/agentService.ts`：`runTurn(webContents, text)` / `abort()`；本轮消息存内存。
- [ ] `src/main/ipc/agentHandlers.ts`：注册 `agent:sendMessage` / `agent:stop`。
- [ ] `src/main/index.ts`：`app.whenReady` 中调用 `registerAgentHandlers()`。

### 5. preload

- [ ] 新建 `src/preload/api/agent.ts`：`sendMessage(text)` / `stop()` / `onEvent(cb)`（返回退订函数）；并入 `src/preload/index.ts` 的 `window.api`。

### 6. renderer

- [ ] `features/agent/hooks/useAgentChat.ts`：删除 mock 打字机；`sendMessage` → `agentApi.sendMessage`；订阅 `onEvent` 按 delta 追加/更新 assistant 消息；`stopStreaming` → `agentApi.stop()`。
- [ ] `AgentPage` / `AgentInput`：接线不变，仅消费新 hook 返回值。
- [ ] 无 apiKey / provider 配置为空时，给出可读错误提示（含跳转设置页入口）。

## 验收

- [ ] 选中 `settings.defaultModel` 对应 provider 后，侧栏输入任意文本获得真实流式回复，Markdown 正常渲染。
- [ ] 回复中按钮切换为"停止"，点击立即终止并保留已产出内容。
- [ ] 无 apiKey 时错误提示可读。

## 校验（docs/standards/code-writing-standards.md）

- 新增 IPC channel：同步 shared 常量 / preload / main handler + 三层契约测试。
- Biome 格式化受影响文件；`pnpm typecheck`；vitest 覆盖 handler 注册与 preload 转发。

## 风险

- 流式事件时序（delta 顺序）；首版单窗口假设。
