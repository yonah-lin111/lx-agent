## 目标

与 pi 功能面基本对齐的收尾能力；清理阶段 1-3 遗留的技术债。

## 前置

- 阶段 3 完成（或按需选择其中几项）。

## 任务清单

### 1. skills 注入

- [ ] 读取项目 `.agents/skills` / `SKILL.md`，注入 system prompt（对齐 pi `skills.ts`）。

### 2. usage-totals

- [ ] 按 provider/model 统计成本与 token（对齐 pi `usage-totals.ts`），展示于会话列表或 footer。

### 3. OAuth / keychain

- [ ] apiKey 改系统 keychain 存储，或接入 provider OAuth 流（对齐 pi `auth-storage.ts` / `packages/ai/src/auth/oauth/`）。

### 4. 正式迁移机制（技术债）

- [ ] 引入 `src/main/db/migrations/` + `schema_migrations` 表；把现有 project / agent 建表纳入正式迁移。
- [ ] 之后 schema 变更一律走新增迁移文件（符合 `docs/standards/code-writing-standards.md`）。

### 5. 扩展点

- [ ] 自定义工具 / slash 命令的类型层扩展（不做 jiti 动态加载）。

## 验收
