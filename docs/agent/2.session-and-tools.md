# 阶段 2：会话 + 工具（P1）

> 主设计见 `docs/agent/0.overview.md`。本文件是 P1 的详细实施清单。

## 目标

- 会话持久化（SQLite），且**一个 project item（提示词条目）对应多个 agent 会话**。
- 会话抽屉（历史列表 / 新建 / 加载 / 删除 / 续聊）。
- 工具系统：只读工具 + MCP + 工具块渲染；模型切换；空状态快捷卡。

## 业务约束

`project_item`(1) → `agent_session`(N) → `agent_message`(N)。会话不挂 project，只挂 project item。

## 前置

- 阶段 1（真实对话）完成，可真实流式对话。
- `src/main/agent` 目录已建立。

## 任务清单

- [ ] `src/main/db/schema/agentSchema.ts`：`createAgentTables(database)` 建 `agent_session`（含 `project_item_id` 外键）、`agent_message`（含 `tool_calls` JSON 列），见主文档 §5.4。

### 4. renderer：会话抽屉 + 归属联动
