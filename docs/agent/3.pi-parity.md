# 阶段 3：对齐 pi（P2）

> 主设计见 `docs/agent/0.overview.md`。本文件是 P2 的详细实施清单。

## 目标

补齐"读-改-写"闭环与 pi 体验对齐：写工具 + 权限确认、bash、compaction、context %、slash 命令、thinking 折叠、对话中追加提问、会话标题。

## 前置

- 阶段 2 完成：会话持久化 + 只读工具 + 工具循环可用。

## 任务清单

### 1. 写工具 + 权限确认

- [ ] `src/main/agent/tools/mutationTools.ts`：`edit` / `write`；首轮返回 diff 待确认，确认后落盘（对齐 pi `edit-diff.ts` / `file-mutation-queue.ts`）。
- [ ] 确认流：写/执行工具发 pending 事件 → renderer 弹确认层 → 确认/拒绝 → 回传 → 继续执行（对齐 pi `project-trust` / `trust-manager` 语义）。
- [ ] `settings` 可设"某目录 / 某工具始终允许"。

### 2. bash 工具

- [ ] `src/main/agent/tools/bashTool.ts`：执行命令、流式 stdout 事件、截断 + 展开（对齐 pi `bash-execution.ts`）。
- [ ] 受确认流保护；可选命令黑名单。

### 3. compaction（上下文压缩）

- [ ] `src/main/agent/context/compact.ts`：超阈值时 LLM 摘要压缩，保留近期 token（对齐 pi `keepRecentTokens` / `reserveTokens`）。
- [ ] 触发策略：上下文百分比超阈值 / LLM 报 context overflow 后压一次并自动重试。

### 4. context % + footer

- [ ] `src/main/agent/context/usage.ts`：按 `model.limit.context` 估算 token 用量。
- [ ] 新建 `AgentFooter`：model + 上下文 % + 运行中停止按钮（对齐 pi `footer.ts`）。

### 5. slash 命令面板

- [ ] 输入框 `/` 补全面板：`/new` `/compact` `/model` `/settings`，选中即触发对应动作（对齐 pi `slash-commands.ts`）。

### 6. thinking 折叠

- [ ] `AgentMessageItem` 渲染 thinking 折叠块（`thinking_delta` 事件已在阶段 1 管道支持）。

### 7. 对话中追加提问

- [ ] 运行中发送消息：排队（followUp）或打断注入（steer）；runtime 消费队列（对齐 pi `Agent.steer/followUp`）。

### 8. 会话标题

- [ ] 用 `settings.titleSummary` 模型在空闲时生成标题，写回 `agent_session.title`。

### 9. 编辑/重发

- [ ] 编辑消息后重发 = 截断到该消息并重新 run（复用现有 `AgentMessageItem` 编辑 UI）。

## 验收

- [ ] agent 修改文件前弹确认，确认后落盘并继续（"读-改-写"闭环）。
- [ ] bash 输出流式显示、可展开查看完整内容。
- [ ] 长对话自动压缩后上下文恢复，footer 显示 context %。
- [ ] `/` 命令面板可用；thinking 可折叠查看。

## 校验

- 写工具 / bash 的确认流单测；compaction 纯函数单测；组件（确认层 / footer / slash 面板）交互测试。

## 风险

- bash / edit / write 的安全边界（权限确认是唯一防线，需充分测试）；compaction 触发时机避免打断用户。
